# SSH_Keys_Generator 1.5.1

A utility that makes it easier to set up SSH key authentication for logging in to a remote server.

## Features

- Generate encrypted PuTTY and OpenSSH private keys and install the public key on a remote server.
- Verify key-based login before optionally disabling SSH password authentication, with a rollback mechanism.
- View, add and remove supported authorized_keys entries with backup and access safeguards.
- Manage multiple server profiles and transfer profiles with private keys in password-protected bundles.
- Check GitHub for updates and download an installer with SHA256 verification.

## Downloads

- SSH_Keys_Generator_Setup.exe — Windows 10/11 x64 installer.
- SSH_Keys_Generator.exe — portable application.
- SSH_Keys_Generator_Source.zip — source and build instructions.
- SHA256SUMS.txt — download checksums.

No real server profiles, credentials, private keys or user logs are included. Existing local profiles and keys are preserved during installation. The executables are not code-signed.
